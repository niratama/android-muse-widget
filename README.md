# Goma Widget (Android ホーム画面ウィジェット)

毎朝 AI アシスタントが Google Drive 内（`goma_widget/widget.json`）に更新する生活データを、Android のホーム画面ウィジェットにコンパクトに表示するアプリです。

- **サーバ不要**: データはお使いの Google アカウント内に閉じます。
- **ダーク／ライト両対応**: システムのテーマに合わせて自動切り替え。
- **即時再取得 & 自動更新**: ウィジェットタップでいつでも即時更新。WorkManager による1時間間隔のバックグラウンド定期更新（省電力設計）。
- **フェイルセーフ**: Drive 取得エラー時も直前の表示内容を消さずに保持。
- **24時間経過表示**: `updated_at` が24時間以上前の場合は、古いデータであることがわかる警告バッジを表示。

---

## 📱 ウィジェット表示イメージ（4行構成）

```
11/10（火） サンプル 晴れのち曇 18/10℃ 雨20%
睡眠 6時間33分 スコア82（深い 3:10 / REM 2:29）
体重 65.0kg（前日比 +0.5）
予定 0件 ／ 今日のゴミ: 可燃ごみ ／ 明日: 資源ごみ
```

- スコアが null の日は `スコアxx` を自動省略
- 体重の節が存在しない日は3行目自体を詰めて非表示
- 予定の `next` がある場合は `（次: 19:00 会議）` を表示

## 🛠️ セットアップ手順

### 1. Google Cloud Console 側の設定

Google Drive の既存ファイル（アシスタントが作成した `widget.json`）を検索・ダウンロードするために、Google Cloud プロジェクトで OAuth 設定を行います。

#### ① 新規プロジェクトの作成 & Drive API の有効化
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 上部ヘッダーのプロジェクト選択ツールをクリックし、右上の **「新しいプロジェクト」** を選択。
   - プロジェクト名: `goma-widget`（任意の名称）
   - 「作成」を押し、作成されたプロジェクトに切り替えます。
3. 左メニュー（≡）「**APIとサービス**」>「**ライブラリ**」を開きます。
4. 「**Google Drive API**」を検索し、「**有効にする**」をクリック。

#### ② OAuth 同意画面の設定（最新UIウィザード）
1. 左メニュー「**APIとサービス**」>「**OAuth 同意画面**」を開きます。
2. 概要ページの中央にある **「開始」** ボタンをクリック。
3. **(1) アプリ情報**:
   - **アプリ名**: `Goma Widget`
   - **ユーザーサポートメール**: 自身の Gmail アドレスを選択
   - 「次へ」をクリック。
4. **(2) 対象**:
   - **「外部」**（External）を選択して「次へ」をクリック。
5. **(3) 連絡先情報**:
   - メールアドレス欄に自身の Gmail アドレスを入力して「次へ」をクリック。
6. **(4) ポリシーへの同意**:
   - ユーザーデータに関するポリシーへの同意チェックボックスにチェックを入れ、「続行」をクリック。
7. 最後に **「作成」** ボタンをクリックして同意画面のベース作成を完了します。

#### ③ テストユーザー & スコープの登録
同意画面作成後、左メニューに表示されるサブメニューから設定を行います：

1. **テストユーザーの追加（必須！）**:
   - 左メニュー **「対象」**（Audience）をクリック。
   - 「テストユーザー」欄の **「+ ユーザーを追加」** をクリック。
   - **スマホ（Pixel）で使用するご自身の Gmail アドレス** を入力して「保存」。
2. **Drive スコープの追加**:
   - 左メニュー **「データ アクセス」**（Data Access）をクリック。
   - **「スコープを追加または削除」** をクリック。
   - フィルタに `drive.readonly` を入力し、一覧の **`.../auth/drive.readonly`**（Google ドライブのすべてのファイルの表示）にチェックを入れる。
   - パネル下部の「更新」を押し、画面下の「保存」をクリック。
   > ※もしフィルタに出てこない場合は、一番下の「スコープを手動で追加」欄に `https://www.googleapis.com/auth/drive.readonly` を貼り付けて追加してください。

#### ④ Android OAuth 2.0 クライアント ID の作成
1. 左メニュー「**APIとサービス**」>「**認証情報**」を開きます。
2. 上部の **「+ 認証情報を作成」** > **「OAuth クライアント ID」** を選択。
3. 設定項目:
   - **アプリケーションの種類**: **「Android」** を選択
   - **名前**: `Goma Widget Android Client`（任意）
   - **パッケージ名**:
     ```text
     jp.poi.widget
     ```
   - **SHA-1 証明書のフィンガープリント**:
     Android Studio または WSL ターミナルで `./gradlew signingReport` を実行して表示される SHA-1 を入力。
     ```text
     5F:F2:68:78:CF:09:09:14:9B:62:21:7A:C5:EB:E5:BF:F5:4F:B6:1D
     ```
   - **アプリの所有権を確認する**: スキップ（操作不要）
   - **このクライアントをAI搭載エージェントに使用する**: OFFのまま（チェック不要）
4. **「作成」** をクリックします（完了画面の JSON ダウンロードは不要です。「OK」を押して閉じてください）。

### 2. Android 端末（Pixel）へのインストール方法

#### 方法 A: WSL からワイヤレスデバッグでインストール（推奨）
1. Pixel の「設定」>「システム」>「開発者向けオプション」>「ワイヤレス デバッグ」を ON にする。
2. 「ワイヤレス デバッグ」の項目をタップし、「ペア設定コードでデバイスをペア設定」を開く。
3. WSL ターミナルでペアリングを実行（※WSL 環境の権限対策として `HOME=/tmp` を付与）:
   ```bash
   HOME=/tmp adb pair 192.168.1.XX:ペアリング用ポート 6桁のペア設定コード
   ```
4. ペアリング成功後、ポップアップを閉じてワイヤレスデバッグ画面に表示されている接続用ポートで接続:
   ```bash
   HOME=/tmp adb connect 192.168.1.XX:接続用ポート
   ```
5. ビルド済み APK をインストール:
   ```bash
   HOME=/tmp adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

#### 方法 B: Android Studio から直接実行
1. Android Studio でこのプロジェクトフォルダを開きます。
2. USB 接続またはワイヤレス接続で Pixel が認識されたら、ツールバーの緑色の **Run ('app')**（▶）ボタンをクリック。

---

### 3. 初回起動とウィジェット配置の流れ

1. Pixel 上で **Goma Widget** アプリを開きます。
2. 「**Googleでサインイン**」ボタンをタップし、GCP のテストユーザーに登録したアカウントを選択。
3. Google Drive の読み取り権限（表示専用）の確認画面が出るので「続行/許可」をタップ。
4. サインイン完了後、「**Driveから今すぐ取得してテスト**」をタップし、Drive からの読み取りが成功することを確認（アプリ内にもプレビューが表示されます）。
5. Pixel のホーム画面の空いている場所を長押しし、「**ウィジェット**」を開く。
6. 「**Goma Widget**」を見つけて長押しし、ホーム画面の好きな場所にドラッグ＆ドロップして配置します。
7. ウィジェットをタップするといつでも即時再取得できます。

## ⚠️ 詰まりやすいポイント & 注意点

1. **スコープとファイルの可視性（解決済み）**:
   - `drive.file` スコープでは、アプリ自身が作成したファイルか、ユーザーが Google Picker で選択したファイルしか見えません。
   - 本アプリではアシスタントが作成した既存の `widget.json` を名前検索で取得するため、`drive.readonly` スコープを採用しています。
2. **OAuth 同意画面の「テストユーザー」登録忘れ**:
   - GCP コンソールで OAuth 同意画面が「テスト中（Testing）」ステータスの間は、テストユーザーに登録されていない Google アカウントでログインしようとすると「エラー 403: access_denied（このアプリはブロックされています）」が発生します。必ず自分の Gmail を追加してください。
3. **SHA-1 の不一致**:
   - PC を変えたりクリーン環境でビルドした場合、`~/.android/debug.keystore` の SHA-1 が変わることがあります。サインイン時に `code: 10` や `DEVELOPER_ERROR` が出る場合は、`./gradlew signingReport` で最新の SHA-1 を確認し、GCP コンソール側の Android クライアント ID に追加登録してください。
4. **Google Drive 上のフォルダ構成**:
   - Google Drive のマイドライブ直下に `goma_widget` フォルダを作り、その中に `widget.json` を配置してください。
   - ※アプリ側の実装では、万が一 `goma_widget` フォルダが見つからなくても、ドライブ全体から `widget.json` をフォールバック検索して自動発見できるように安全設計されています。
5. **バックグラウンド更新とバッテリー最適化**:
   - 本アプリは Android 標準の `WorkManager`（1時間間隔・Wi-Fi/モバイル通信接続時のみ）を採用しており、無駄な定期通信を行わない省電力設計になっています。
   - Pixel の「バッテリー使用量の最適化」が「制限あり」になっていると定期更新が遅延することがあるため、確実に1時間ごとに最新化したい場合は、アプリ情報からバッテリー設定を「最適化」または「制限なし」にしてください。
